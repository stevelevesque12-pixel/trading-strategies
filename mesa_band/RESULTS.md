# MESA Phase Band Trend -- backtest results

Generated by `python -m mesa_band.run` (a Python port of `tradingview/mesa_phase_band_trend.pine`, default inputs).

Settings: stop 2.0x ATR(14), target 2.0R, risk $250/trade, max 50 micros, entries 0930-1530 ET, flat by 1555 ET, max 4 trades/day, daily loss guard $900. Costs: $0.62/side commission per micro + 1 tick slippage on market and stop fills.

Caveats: the 2016-26 rows use full-size ES/NQ/GC prices with micro point values (unadjusted continuous contracts, so roll gaps can cause a false regime flip; positions are always flat overnight so gaps never hit P&L directly). There is no long MCL history in the repo. The 5m micro set is only ~3.5 months (4 evaluation starts), too short to conclude anything. Fills are simulated from OHLC bars, not ticks.

## Prop evaluations (50K, $3000 target, $2000 end of day trailing max loss)
